# Archived retrieval experiments

`rag_legacy_2026-03-10/` preserves the earlier LangChain/Gemini retrieval experiments, notebooks and reference documents. It is not used by the current application or installed with its dependencies.

Use `agentic_rag/` for the maintained backend. Existing reference texts, URLs and acknowledgements are retained; inclusion does not imply authorship of third-party source material. Notebook execution outputs have been cleared for publication, and historical hard-coded credentials have been removed from imported versions.
