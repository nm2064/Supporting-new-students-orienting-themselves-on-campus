# Supporting-new-students-orienting-themselves-on-campus
This repository contains the research, design, and implementation materials for my BSc Computer Science dissertation at Heriot-Watt University. This project aims to develop an AI-powered application based on Large Language Models (LLMs) to support new students, with a special focus on international students, in their onboarding and daily navigation within Heriot-Watt. The app will serve as an intelligent assistant, providing personalised guidance on university services, campus facilities, administrative procedures, academic resources, and cultural integration. Key features will include multilingual support, interactive campus navigation, and context-aware answers tailored to Heriot-Watt’s environment. By combining conversational AI with geolocation and official university information, the solution will help students quickly adapt to campus life, reduce uncertainty, and foster a more inclusive and welcoming experience.
